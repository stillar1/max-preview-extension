# MAX File Previewer

Мощное Chrome-расширение для корпоративного мессенджера MAX, которое позволяет просматривать, читать и даже запускать отправленные файлы прямо в браузере, избавляя вас от необходимости скачивать их на компьютер.

## ✨ Поддерживаемые форматы

- 📄 **Офисные документы:** `.docx`, `.xlsx`, `.xls`, `.pptx`, `.pdf`, `.rtf`, `.odt`
- 📦 **Архивы:** `.zip` (со встроенным проводником и возможностью предпросмотра файлов прямо из архива)
- 💻 **Исходный код:** `.py`, `.js`, `.c`, `.cpp`, `.java`, `.cs`, `.go`, `.php`, `.rb`, `.swift`, `.ts`, `.sh`, `.html`, `.css`, `.xml`, `.json`, `.md` (с красивой подсветкой синтаксиса)
- 🚀 **Исполняемый код:** `.py` (Python) и `.js` (JavaScript) можно **компилировать и запускать** прямо в браузере с выводом результата в консоль!
- 🎬 **Медиафайлы:** `.mp4`, `.webm`, `.ogg`, `.mp3`, `.wav`
- 🖼 **Изображения:** `.png`, `.jpeg`, `.jpg`
- 📝 **Простой текст:** `.txt`, `.csv`

## 🛠 Установка
1. Откройте вкладку `chrome://extensions/` в вашем браузере.
2. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked).
4. Выберите папку с исходным кодом этого расширения.
5. Готово! Теперь при клике на файл в мессенджере MAX он откроется в новой удобной вкладке предпросмотра.

## ⚙️ Особенности
- **Абсолютная безопасность:** Запуск пользовательского кода (`.py`, `.js`) происходит в строгой "песочнице" (sandboxed iframe), что гарантирует отсутствие вредоносного воздействия на расширение или браузер.
- **Поддержка буфера обмена:** Правильное копирование таблиц из Excel-документов (вставляются без искажения HTML разметки).
- **Всё включено:** В случае, если предпросмотр не поддерживается, расширение покажет удобную заглушку с кнопкой для скачивания оригинального файла.
